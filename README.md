# Cardinal Agency CRM — white-label demo

The unified agency system: one login for quoting, carrier portals, ID cards, certificates,
payments, renewals, drip campaigns, tasks and ad reporting.

Open `index.html`. Access code: `cardinal2026`.

What to click, in order:
1. Dashboard — book of business, renewals at risk, today's queue, spend and lead source.
2. Clients — one record per household. Open any row for the 360 view.
3. Client record — policies per carrier, ID card, certificate, declarations, payment, household,
   residence, vehicles, coverages, prior carrier, quotes and policies, EZLynx deep link.
4. Carrier login — for markets without an API: vault credentials, you complete MFA, the system
   pulls only that client, then the portal rates and the quote is captured back into the record.
5. Role switcher, top right — Owner sees the agency. Producer or CSR sees only their own book:
   no agency totals, no ad spend, no other producers, no admin settings.
6. Quotes — rate across seven markets and bind in place.
7. Policies — renewals, payment status, lapse risk.
8. Tasks — follow-up queue plus out-of-office coverage handoff.
9. Campaigns — nurture, quote follow-up, renewal save, payment reminder, birthday, cross-sell.
10. Growth — spend, CPL, quote rate, cost per bound policy, lead flow, ZIP density.
11. Data sync — EZLynx pull, carrier portals, website lead forms.
12. Security — the production controls behind the white-label promise.

Positioning: EZLynx stays as the system of record. This replaces the four to six tools around it
with one, and it does not charge per seat as the agency hires.
